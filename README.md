Neon Heist Canvas — an SVG poster studio that turns any photo and caption into GTA 6-style cover art: seven data-driven layouts, clip-path photo panels with per-panel fit, anchor, zoom and grade, a code-drawn Vice City sunset backdrop, and PNG export in four post sizes. It runs fully offline in a desktop browser, and the photos never leave the machine.

## Run it

```sh
node serve.ts
```
