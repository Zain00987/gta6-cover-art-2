Neon Heist Canvas — a GTA 6-style cover art maker with six diagonal and offset layouts (solo, diagonal duo, hero slant, offset strips, staggered quad, triptych), per-panel colour grades, a code-drawn Vice City sunset backdrop (gradient sky, striped sun, palm silhouettes), multi-zone typography (title, subtitle ribbon, tagline, stamp badge), film grain and halftone, and PNG export at 1080×1080, 1080×1350, 1080×1920 and 1920×1080. Runs fully offline in a desktop browser; your photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080, load one or more photos (or use the two bundled samples), pick a layout, grade each panel, write your title, subtitle and tagline, and export the PNG. One click on “Surprise me” builds a whole random poster.
